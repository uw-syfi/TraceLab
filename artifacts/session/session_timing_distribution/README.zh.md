# 记录时间分布

本报告使用 `artifacts/utils/request_timing.py`，与子代理计时共享请求分组、工具时间及覆盖率定义。

工具时间为已知正值之和：优先使用 `tool_internal_latency_ms`，否则使用 `tool_wall_latency_ms`。它是归属到请求的工具工作量，包含交互工具等待，并非独占执行时间。观测响应跨度不是实际模型推理时间；输入间隔也不一定来自人类。

请求耗时要求原生开始与完成证据。中止、未完成、缺少开始、冲突及压缩时间戳均不产生请求耗时。旧记录保留可计数的推断请求组；下一个提示和文件结束不代表完成。工具工作量不除以短响应耗时；只有明确命名、限定在请求区间内的工具等待并集可计算墙钟比例。

缺少工具时间、原生网页搜索开始时间或匿名工具观测均须报告覆盖缺口。内部耗时为正但发出和结果时间相同的记录不适合墙钟比例。`N/A` 表示不可测，绝不是零。会话比例使用相同合格会话的总量之比；重叠的工作量不能解释为互斥计算时间。

详细定义与运行方式见 [英文说明](README.md)。生成输出必须与当前输入数据一同重建；不使用旧叙述数值替代新结果。
